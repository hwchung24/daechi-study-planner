# 카카오 알림톡(Solapi) 템플릿 정리

대치루트 앱에서 **학부모 인앱 알림**을 **카카오 알림톡**으로 보낼 때 필요한 설정과, **Solapi「새 템플릿 등록하기」화면에 맞춰 무엇을 어떻게 채울지**를 정리한 문서입니다.

---

## 1. Solapi 화면 순서별 — 양식 채우기 가이드

아래는 Solapi 콘솔 **알림톡 템플릿 등록** 흐름(채널 선택 → 내용 입력 → 보안/대체 → 검수 요청)에 맞춘 체크리스트입니다.

### 1단계: 새 템플릿 등록 (채널·카테고리·유형)

| 항목 | 권장 입력 | 비고 |
|------|-----------|------|
| **채널 또는 그룹 선택** | 실제 발송에 쓰는 카카오 채널 (예: `@root-daechi`) | PFID와 동일 채널이어야 함 |
| **카테고리 그룹 선택** | 안내에 맞는 그룹 선택 | 교육·학원 서비스 안내에 맞는 항목이 있으면 **기타**보다 우선 검토 |
| **카테고리 선택** | 세부 카테고리 | 검수 시 **발송 사유·수신 대상**이 드러나도록 선택 |
| **템플릿 유형** | **기본형** | 학부모 알림은 텍스트 중심이면 기본형이면 충분함. 강조표기·이미지·리스트형은 디자인 필요 시만 |

상단의 **샘플 템플릿 둘러보기**, **템플릿 제작 가이드**, **필독! 심사 가이드**는 등록 전에 한 번 읽는 것을 권장합니다.

---

### 2단계: 템플릿 내용 (이름·본문·부가정보)

| 항목 | 권장 입력 | 비고 |
|------|-----------|------|
| **템플릿 이름** | 내부용 (수신자에게 안 보임). 예: `학부모_앱알림_통합` | 팀에서 구분만 되면 됨 |
| **내용** | 아래 **「학부모 앱 알림용」** 예시처럼 변수 포함 본문 | **변수 추가** 버튼으로 `#{알림전문}` 등 등록. 변수명은 발송 API의 `variables` 키와 **글자 하나까지 동일**해야 함 |
| **부가정보** | 선택. 예: `문의: OO학원 / 운영시간 9~18시` | 이 영역은 **변수 사용 불가** (화면 안내 기준) |
| **이모티콘·특수문자** | 필요 최소한 | 검수·브랜드 톤에 맞게만 사용 |

**내용** 하단에 **현재 N자 / 최대 1,000자**가 표시됩니다. 치환 후 전체가 1,000자 이내인지 확인합니다.

---

### 3단계: 보안 템플릿 · 알림톡 버튼 · 변수 목록 · 대체발송

| 항목 | 학부모 앱 알림 템플릿 | 비고 |
|------|----------------------|------|
| **보안 템플릿** | **사용 안 함(OFF)** | 비밀번호·**인증번호** 등 민감 정보는 보안형(모바일 카카오톡에서만 열람)에 맞춤. **일반 서비스 안내·학습 알림**은 보통 OFF |
| **알림톡 버튼** | 선택 | 「앱에서 보기」 등은 **앱 설치 유도로 심사 반려**될 수 있어 문구·링크는 **심사 가이드**와 맞출 것 |
| **사용 변수 목록** | 본문에 넣은 `#{…}` 가 자동 집계되는지 확인 | 빠진 변수가 있으면 검수/발송 오류 가능 |
| **대체발송 설정** | 정책에 따라 선택 | **대체발송 메시지 지정**: 알림톡 실패 시 SMS 등. **대체발송 안함**: 백업 없음. 현재 서버 코드는 알림톡 API에서 `disableSms: true` 로 두는 경로가 있어, **콘솔 대체발송**과 **API 옵션**을 함께 맞춰야 모순이 없습니다 |

> **회원가입 인증번호**는 현재 구현상 **일반 SMS(`sendSolapiSms`)** 로 보냅니다. 인증번호만 **알림톡 보안 템플릿**으로 바꾸려면 별도 템플릿 + 발송 코드 변경이 필요합니다.

---

### 4단계: 검수 요청 (의견 제출 · 반려 유의 · 미리보기)

| 항목 | 권장 입력 |
|------|-----------|
| **등록 완료 후 즉시 검수요청** | 켜두는 경우가 많음 | 바로 카카오 검수 넣을 때 |
| **검수자 참고 의견 (선택, 500자)** | 아래 **예시 문구** 참고 | 수신자·발송 사유를 짧게 명시하면 승인에 유리 |

**반려되기 쉬한 내용 (화면 안내 요지)** — 아래에 해당하면 템플릿이 **반려**될 수 있습니다.

1. 알림톡으로 **광고** 성격의 내용  
2. **수신 대상**과 **발송 사유**가 불명확  
3. 혜택 조건으로 **개인정보 수집 등 특정 행위 유도**  
4. **앱 설치 유도** 문구  

하단 **「위 내용을 확인했으며 해당 사항이 없습니다」** 는 반드시 체크합니다.

**미리보기**는 실제 단말과 다를 수 있으므로, 승인 후 테스트 발송으로 한 번 더 확인합니다.

---

### 검수자 참고 의견 — 붙여넣기 예시 (학부모 앱 알림 1종)

```text
대치루트 학습 플래너에 연결된 학부모 계정에 한해, 앱 내 알림(학습·연결·요청 등 서비스 운영 알림)과 동일한 내용을 카카오 알림톡으로 발송합니다. 수신 동의·앱 이용 약관에 따른 정보성 알림이며 광고·마케팅 목적이 아닙니다.
```

(학원명·서비스명은 실제 명칭으로 바꿉니다.)

## 2. 등록할 템플릿 본문 예시 (학부모 앱 알림 · 1종 권장)

알림 종류가 많으므로 **변수 1개**에 제목+본문을 모두 넣는 형태를 권장합니다.

**템플릿 이름 (내부용):** 예) `학부모_서비스알림`

**내용 (본문):**

```text
[대치루트] 학습 관련 알림이 도착했습니다.

#{알림전문}

※ 본 메시지는 발신 전용입니다.
```

- Solapi 발송 시 `variables` 예: `{"#{알림전문}": "첫 줄 제목\n둘째 줄 이후 본문…"}`  
- 변수명 `#{알림전문}` 은 **템플릿에 적은 것과 완전히 동일**해야 합니다.

> **현재 서버**는 `message.text` 위주로 보내는 경로가 있어, 검수 통과 템플릿이 **변수 치환만** 허용하면 `kakaoOptions.variables` 로 맞추는 편이 안전합니다.

---

## 3. 현재 서버가 만드는 알림 문자열 (변수에 넣을 값)

`server/parentKakaoNotify.js` 기준:

| 구성 | 설명 |
|------|------|
| 첫 줄 | 인앱 알림 **제목** (`title`) |
| 이후 | 인앱 **본문** (`body`). `[[DAECHI_ACTION]]` 접두가 있으면 제거한 뒤 노출 부분만 사용 |

**예시 (`#{알림전문}` 한 덩어리):**

```text
오늘 계획 수정 요청
홍길동(이)가 2026-05-10 18:00-19:00 수학 계획 수정을 요청했어요.
```

발송 API: `server/solapiService.js` → `sendKakaoAlimtalk`  
(`pfId`, `templateId`, 본문/`variables`, `disableSms` 등)

---

## 4. 학부모 회원가입 인증번호 (참고)

- **현재:** 휴대폰 인증번호는 **SMS(LMS)** 로 발송 (`sendSolapiSms`).  
- **알림톡 템플릿**은 이 경로에 필수는 아님.  
- 나중에 **알림톡 + 보안 템플릿**으로 바꿀 경우: 별도 템플릿(변수 `#{인증번호}` 등) + **보안 템플릿 ON** + 발송 코드 수정이 필요합니다.

---

## 5. 서버 환경 변수 (.env)

| 변수 | 용도 |
|------|------|
| `SOLAPI_API_KEY` / `SOLAPI_API_SECRET` | API 인증 |
| `SOLAPI_SENDER` | 발신번호 (알림톡·SMS 공통) |
| `SOLAPI_KAKAO_PFID` | 카카오 채널 PFID |
| `SOLAPI_KAKAO_TEMPLATE_ID` | 승인된 **학부모 알림** 템플릿 ID |
| `SOLAPI_ENABLE_PARENT_KAKAO_NOTIFICATIONS` | `false`/`0`/`no` 이면 알림톡 발송 안 함. 비우면 발송 시도 |

---

## 6. 길이·운영 유의

- 치환 후 본문 **최대 약 1,000자** (화면·정책 기준 준수).  
- 학부모 **알림 설정**에 따라 인앱이 안 만들어지면 카톡도 가지 않음.  
- **앱 설치 유도**, **광고성 문구**는 검수·정책상 피할 것.

---

## 7. 템플릿 개수 요약

| 용도 | 개수 | 비고 |
|------|------|------|
| 학부모 앱 알림 → 카카오 | **1개** | `#{알림전문}` 등 변수형 1종 권장 |
| 회원가입 인증 (현재) | **0개** | SMS 사용 시 알림톡 불필요 |

---

## 8. 관련 소스

| 파일 | 역할 |
|------|------|
| `server/solapiService.js` | Solapi 인증, 알림톡·SMS 발송 |
| `server/parentKakaoNotify.js` | 학부모 전화번호, 본문 조합, 알림톡 호출 |
| `server/index.js` | 인앱 알림과 연동 |
| `server/aiReportService.js` | 일일 AI 리포트 알림 |
