# Haptics Guidelines

대치루트 앱의 햅틱은 "보이는 애니메이션을 보강"하는 수준으로만 사용합니다. 기본 원칙은 아래와 같습니다.

- 한 액션에 햅틱은 1회만 사용합니다.
- 네트워크 요청 시작 시점보다 결과 시점의 피드백을 우선합니다.
- 반복 조작에는 `selection` 또는 `light`만 사용하고, `warning`/`success`는 드물게 씁니다.
- 같은 종류의 햅틱은 짧은 쿨다운 안에서 반복 호출하지 않습니다.

## Global Rules

- `selection`: 탭 전환, segmented control, 날짜/시간 피커처럼 값이 바뀌는 순간
- `light impact`: 체크 완료, 카드 확장, 짧은 상태 전환처럼 가벼운 확정 액션
- `medium impact`: 앱 전체에서 정말 큰 전환에만 제한적으로 사용
- `success`: 저장 완료, 로그인 성공, 승인 완료처럼 사용자가 기다린 결과
- `warning`: 서버 실패, 네트워크 실패, 되돌릴 수 없는 오류

## Screen Rules

- 로그인 화면: 로컬 입력 검증에는 무진동, 서버 실패/네트워크 실패만 `warning`, 성공만 `success`
- 오늘 기록/내일 계획 저장: 저장 시작에는 무진동, 완료 시 `success`, 전체 실패 시만 `warning`
- 날짜/시간 피커: 값이 실제로 바뀐 경우에만 `selection`, 이미 선택된 값을 다시 누를 때는 무진동
- 체크리스트/완료 토글: `light impact`만 사용하고 `medium`은 피함
- 승인/거절/삭제: 탭 순간보다 서버 결과에 맞춰 `success` 또는 `warning`

## Anti-Patterns

- 같은 버튼 탭에 즉시 햅틱을 주고, 성공 응답 때 다시 한 번 주는 패턴
- 입력 오류마다 강한 `warning`을 반복하는 패턴
- 스크롤 중 매 프레임 햅틱을 호출하는 패턴
- 같은 값을 다시 선택해도 계속 햅틱이 울리는 패턴
